# Flutter & Dart Quiz Prep

Study materials for Mobile Application Development (MAD) — Flutter & Dart fundamentals.

Designed for absolute beginners preparing for a lab quiz. Covers the 9 core concepts: Flutter vs Dart, the entry point, variables and types, collections, null safety, functions, Stateless vs Stateful widgets, common widgets, and TextField + TextEditingController.

## Contents

| File | Purpose |
|---|---|
| [`QUESTIONS.md`](QUESTIONS.md) | 36 practice questions with collapsible answers, code snippets, and explanations |
| [`STUDY_GUIDE.md`](STUDY_GUIDE.md) | Concept-by-concept walkthrough + cheat sheet + night-before recap |

## How to use

1. **Read `STUDY_GUIDE.md`** first — understand the concepts.
2. **Try `QUESTIONS.md`** closed-book — collapsed `<details>` tags hide the answers until you click.
3. **Review the night-before recap** in `STUDY_GUIDE.md` Part 3 before the quiz.

## Topics covered

- What Flutter is vs what Dart is (UI framework vs language)
- The Dart entry point (`void main()`)
- Variables: `var`, `final`, `const` — when each is required
- Types: `int` vs `double` (they're not the same!)
- Strings, the curly-brace trap, interpolation, parsing
- Collections: List `[]`, Set `{}`, Map `{k: v}`
- Null safety with the `??` operator
- Functions: positional vs named parameters, `required` modifier
- Widgets: `StatelessWidget` vs `StatefulWidget`, where `build()` lives
- Common widgets: `MaterialApp.home`, `Scaffold.appBar`, `child:` vs `children:`
- Buttons and their required parameters
- `TextField` + `TextEditingController` (reading and clearing input)
